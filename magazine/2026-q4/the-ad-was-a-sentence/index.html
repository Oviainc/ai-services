The Ad Was a Sentence: Prompt Adware and the Instruction File

A free jailbreak bundle hid a standing advertisement inside a coding agent's global instructions, and the payload was pure wording — a case for reading instruction files the way code gets read.

Ovia Inc · Studio and Lab · 6 min read

The advertisement arrived as a sentence. No banner, no pop-up, no executable file for a scanner to catch — one line of plain language, placed inside a file the agent trusted, written to fire every time a user said hello.

On November 3, 2026, Check Point Research published its analysis of Haiou, a jailbreak bundle built for a coding agent, and gave the pattern a name: prompt adware. The definition deserves a slow read. Prompt adware persistently alters an agent's trusted instructions — global prompts, Skills, or configuration files — to influence future outputs for commercial or behavioural objectives. The payload is not code. The payload is wording.

Key points

  • A jailbreak bundle for a coding agent carried a second, quieter payload: a persistent advertisement written into global instruction files.
  • The advertising rule sat in an identity module and fired on ordinary greetings and activation words.
  • The advertised service is an opaque gateway between applications and model providers; the researchers found no evidence the gateway itself is malicious.
  • The same persistence can steer recommendations, vendor choices and technical advice without the user's awareness.

01 · The announcement

Check Point Research began somewhere else entirely: a misconfigured webserver run by an actor operating the Cobalt Strike framework. Alongside that server's logs sat a toolkit — the Ladon network scanner, the VulnClaw penetration-testing agent, and Haiou. Haiou means Seagull. The bundle sets out to jailbreak a coding model: security requests reframed as educational Capture The Flag exercises, refusals suppressed through role-play and persona overrides, and a set of security-focused Skills covering penetration testing, reverse engineering, licence security, memory analysis, laboratory work and game security.

Then comes the part that earned the new name. Inside the bundle's identity module sat a standing rule: when the user offers an exact greeting or activation word — hi, hello, hey, yo, ctf, coach, and their equivalents — reply with a fixed catchphrase and an advertisement for a gateway service, and nothing else. Every casual hello became an ad slot, and the rule reloaded at the start of every session, because the instruction file is read again each time the agent starts.

02 · Why it matters

Adware used to announce itself. Banners multiplied, homepages changed, toolbars appeared uninvited. Prompt adware whispers. The agent still sounds like the agent. Tone, skill and workflow remain intact; only the instructions underneath have been edited, and the edit survives every restart. Persistence used to require malware craft — registry keys, scheduled tasks, services. Here persistence requires a sentence in the right file.

The distribution was ordinary, too. The bundle sits on GitHub, where the researchers counted more than two hundred fifty stars, promoted in a video on Bilibili, discussed in a QQ group, and bundled inside Codex-X, a graphical tool for configuring the same agent. The payload itself arrived encrypted: launchers for Linux, macOS and Windows verify a signature and a hash, then decrypt the prompt files with an embedded key, leaving the wording opaque to anyone browsing the repository. A free jailbreak as the funnel, a paid gateway as the business — the researchers read the model plainly: free the model, sell the gateway.

The payload is not code. The payload is wording.

03 · The craft angle: instruction files are code

Context engineering at Ovia since December 2022 starts from a blunt premise: an agent treats its instructions as ground truth. The model does not audit the file it was raised on. That makes every global prompt, every Skill and every configuration file part of the trusted base — and anything trusted needs change control. The field habits are unglamorous and effective. Instruction files get reviewed before installation and diffed whenever they change, the way code is reviewed. Bundles from unknown authors get read in full before a single file lands, and encrypted payloads that refuse reading get refused in turn.

Gateways and relays between an application and a model provider get named, vetted and logged, because a relay sees the traffic; the researchers cite a study in which some gateways snooped on user data, took secrets such as cloud access keys, and in some cases injected tool calls into the routed session. Eight years coordinating technology at Staywired, from 2014 to 2022, taught the same lesson on physical networks: the configuration nobody remembers approving is the configuration that fails — or misbehaves — first. An uninstaller, to its credit, ships with the bundle and restores the original configuration. Defence cannot depend on the courtesy of the package.

04 · Caveats and fine print

Precision matters here, because the headline invites overreach. The researchers found no evidence linking the bundle's author to cybercrime, and no indication that the advertised gateway itself is malicious. The bundle was observed in a threat actor's toolkit, alongside Cobalt Strike, which makes the package dual-use and present in real criminal ecosystems — a different claim from authorship, and the report keeps the two apart. A second coding assistant, tested with the same payload, flagged the injection attempt and declined to follow the injected instruction; the advertising rule never made the repository prepared for that assistant. The analysed version is one version, numbered 4.5.0 by its author, of one bundle. What generalises is not the bundle. What generalises is the mechanism: trusted natural-language files, edited once, steering every later answer.

05 · What to watch

Watch the economics first. A jailbreak bundle is now a distribution channel, and distribution channels attract advertisers before they attract regulators. The quiet variants matter more than the loud one: an instruction that steers product recommendations toward a preferred vendor, colours a comparison, or inserts a relay into every workflow will not announce itself with a catchphrase. Watch, second, the review surface. Registries that host Skills, prompt packs and configuration bundles inherit the adware problem the moment downloads scale; scanning wording is harder than scanning binaries, and the wording here arrived encrypted. Watch, finally, the audit habit inside teams: a standing inventory of instruction files, an owner named for each, and a diff reviewed before any bundle update lands.

We build agents to follow instructions faithfully. Haiou is the reminder that faithfulness cuts both ways: the file deserves the same suspicion as the stranger. Read the instructions. Own the instructions. The agent will do the rest — exactly as written.
